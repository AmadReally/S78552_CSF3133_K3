## 📚 Apa yang dipraktikkan
 
- Struktur dokumen HTML5 (`<head>`, `<body>`, `<meta>`, `<title>`)
- Heading, paragraph, bold, italic dan line break
- Ordered list, unordered list dan description list
- Link biasa, relative link dan e-mail link (`mailto:`)
- Imej dengan `alt` text
- `<blockquote>` dan special characters (`&copy;`, `&amp;`)
- Komen HTML dan validation menggunakan [W3C Validator](https://validator.w3.org)
